# 巡检宝当前功能模块清单

本文记录当前代码库中已经具备的功能边界，供后续与街道客户沟通、排期和部署使用。标记为“界面流程”的功能已具备交互原型，但尚未接入对应的生产自动化服务。

## 1. 平台入口与权限

- 登录页、管理员会话校验和退出登录。
- 顶部导航统一进入地图总览、项目档案、媒体库、巡检报告、已发现问题、地图资产和审计。
- 后端提供健康检查和登录接口；数据库使用 PostgreSQL 保存业务数据。

## 2. 地图总览与标绘

### 已落地能力

- 首页加载曲阳街道二维瓦片地图，支持缩放和浏览。
- “地图”模块支持上传 XYZ 瓦片压缩包、识别瓦片范围与层级、发布为首页当前底图。
- 首页可在地图上绘制道路折线、圈选小区闭环区域、绘制重点点位。
- 小区区域闭合后可填写名称并关联小区档案；道路和重点点位同样可关联对应档案。
- 每个标绘支持六种边框颜色：蓝、青、绿、橙、红、紫。
- 进入编辑后，点击区域即可修改名称、拖动顶点调整范围、保存修改或删除标绘；删除仅删除地图标绘，不会删除关联档案。
- 首页点击已关联的小区、道路和重点点位，可跳转到相应档案页。

### 后端能力

- 地图资产、瓦片元数据、标绘几何、颜色和关联档案保存到 PostgreSQL。
- 地图标绘新增、更新、删除均写入操作审计。
- 瓦片通过受控接口读取，避免任意文件路径访问。

## 3. 项目档案管理

### 已落地能力

- “项目”下分为小区档案、道路街面、重点点位三个同级入口。
- 支持新增小区、道路和重点点位，包含名称、状态和分类等基础信息。
- 每个档案可查看关联问题、巡检报告和历史信息。
- 档案页保留问题照片墙、问题明细和处置时间线的呈现位置。

### 当前边界

- 档案详情的图片墙需要由媒体库的真实照片和问题关联关系驱动；当前已有数据呈现与关联接口基础，完整自动推送在媒体闭环模块实施。
- 小区、道路、点位的编辑和删除接口仍应作为下一阶段的独立后台能力补齐，避免误删影响问题和报告引用。

## 4. 媒体库与视频巡检分析

### 已落地能力

- 媒体库已提供视频任务、待复核类型、疑似问题事件、任务状态、复核入口和生成报告入口的交互工作台。
- 支持维护识别分类维度，例如工程机械、工程车辆、裸土堆料、临时建筑；分类名称和关键词可在当前浏览器中维护。
- 疑似事件详情可展开、关闭，并可进入报告编写页面。

### 当前边界

- 视频上传、抽帧、YOLO 推理、事件合并和视频片段裁剪目前是界面流程与业务模型，尚未部署真实异步分析服务。
- 下一阶段需要接入对象存储、Redis 队列、视频抽帧服务和模型推理服务，并把识别结果写入 PostgreSQL 的媒体、分析任务、帧和事件表。

## 5. 问题发现与闭环台账

### 已落地能力

- 问题台账支持问题列表、按关键词和状态筛选、问题详情、状态更新和附件上传。
- 问题可关联小区、道路或重点点位。
- 目前状态覆盖待处理、处理中、已整改、复查通过、误报/归档等基础闭环状态。

### 后续对接方向

- 视频分析确认后的事件应自动生成“待复核问题”；人工确认后推送到问题台账和对应项目档案。
- 每个问题后续应关联证据照片、视频时间点、视频片段和地图坐标。

## 6. 巡检报告管理

### 已落地能力

- 报告管理页支持查询、查看、下载和上传已有报告文件。
- 后端保存报告文件元数据、关联对象、报告日期、类型和问题数量；文件存储在独立存储目录。
- 报告编写页支持上传巡检图片、图片切换、矩形框、箭头、文字说明、撤销/恢复、图片说明暂存和逐张填写。
- 图片信息区域可显示文件、时间、设备、经纬度等信息；页面提供二维码定位的界面位置。

### 当前边界

- 报告编写页当前提交使用浏览器本地归档机制，用于演示填写流程；多人共享的“正式提交报告”接口、证据图片持久化和 Word/PDF 生成仍需接入后端。

## 7. 地图资产与更新

- 地图资产页管理图片底图和 XYZ 瓦片包。
- 可上传并发布新瓦片地图，首页加载当前发布版本。
- 后续定期更新时，只需在“地图”模块上传新瓦片、核对范围并发布；历史标绘可在发布前由人工校验和迁移。

## 8. 操作审计

- 后端记录新增档案、地图标绘新增/修改/删除等关键操作。
- 审计页面可按操作、对象类型和关键字查看记录。
- 后续应把媒体复核、问题状态改变、报告提交和地图发布纳入同一审计链路。

## 9. 数据库与部署底座

- 主业务库已从 SQLite 切换为 PostgreSQL，适合多用户的档案、问题、报告、地图和审计数据。
- 提供 SQLite 历史数据一次性导入工具，防止旧数据丢失。
- 腾讯云生产建议使用 TencentDB for PostgreSQL 内网连接；上传照片、视频、瓦片和导出报告应迁移到腾讯云 COS。
- Redis 预留给视频抽帧、AI 识别、事件合并和报告生成等异步任务，不替代 PostgreSQL。

## 10. 当前实施顺序

1. 完成地图标绘、档案编辑和媒体照片关联的业务数据闭环。
2. 接入视频上传、对象存储、异步任务队列和 AI 识别服务。
3. 将已确认事件自动推送至问题台账、项目档案和报告编写。
4. 实现正式报告提交、Word/PDF 导出、权限分级和线上运维监控。
