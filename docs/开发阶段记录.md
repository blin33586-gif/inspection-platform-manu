# 巡检宝开发阶段记录

## 2026-07-11 媒体任务详情页与抽帧间隔

### 本阶段目标

- 视频上传时允许在 `1-5 秒/帧`之间选择抽帧间隔。
- 媒体库列表只展示任务，不再把抽帧照片或图片包照片堆在列表底部。
- 点击真实任务进入站内独立详情页，集中查看原始视频和任务素材。

### 新增能力

- 抽帧参数：
  - 管理端提供 `1 秒/帧`至`5 秒/帧`五个选项，默认 3 秒。
  - API 和媒体工作进程统一接受整数 1 至 5。
  - 0、6 和非整数参数被拒绝，不创建抽帧任务。
- 任务详情：
  - 新增 `/media-library/:taskId` 路由。
  - 单任务接口返回最新处理任务和首张子素材摘要。
  - 页面展示素材类型、处理方式、素材数量、文件大小和处理进度。
  - 视频任务可通过支持 HTTP Range 的播放器查看原始巡检视频。
  - 视频抽帧和 ZIP 图片统一使用素材画廊，支持大图预览和“写报告”。
  - 详情页提供“返回媒体库”，不新开浏览器标签页。
- 列表调整：
  - 真实任务卡点击后进入详情页。
  - 演示任务仍保留当前页面的疑似事件交互。
  - 删除列表底部素材预览，避免大量图片拉长任务列表。
  - 上传成功后直接进入新任务详情页查看处理状态。

### 已验证

- API 1 秒和 5 秒抽帧任务可创建，0 秒和 6 秒被拒绝。
- 媒体工作进程接受 1 秒输入，FFmpeg 参数生成为 `fps=1/1`。
- 浏览器抽帧下拉展示 1 至 5 秒五个选项。
- 媒体库列表不再出现素材预览区。
- 真实任务进入独立详情页，原始视频可播放，86 张历史抽帧照片可查看。
- 抽帧照片“写报告”跳转后，目标图片自动进入报告标注画布。

### 模块边界

- 本阶段不修改数据库结构、AI 识别、事件合并和报告编辑器内部标注逻辑。
- 媒体任务详情页作为已定型的媒体预览入口，后续 AI 结果叠加在该页面继续扩展。

## 2026-07-11 统一媒体任务与素材预览

### 本阶段目标

- 将视频和图片压缩包统一为媒体库“任务”，不再把任务列表限定为视频任务。
- 视频上传后由媒体工作进程离线抽帧，图片 ZIP 上传后由同一工作进程安全解压。
- 处理结果回写媒体库，任务下可预览抽帧照片或图片包照片，并可直接进入报告编写。

### 新增能力

- 统一任务接口：
  - 上传接口自动识别 `MP4`、`MOV` 和 `ZIP`。
  - 统一任务列表返回视频、图片包、处理状态、素材数量和事件数量。
  - 提供任务子素材查询与单个媒体详情查询。
- 图片包安全处理：
  - 只接收 `JPG`、`JPEG`、`PNG` 图片。
  - 校验文件签名，拒绝路径穿越、绝对路径、软链接、加密条目和异常压缩包。
  - 限制单文件大小、图片数量和总解压体积。
  - 嵌套目录平铺到同一任务，重复文件名自动追加序号。
- 媒体内容访问：
  - 图片通过鉴权接口完整返回。
  - 视频支持 HTTP Range，满足浏览器按需加载和拖动播放。
  - 存储路径经过边界校验，禁止访问任务目录之外的文件。
- 管理端交互：
  - 列表统一显示“任务”“任务数”“上传素材”和“重新处理”。
  - 视频任务鼠标悬停时静音循环预览，移出后恢复封面，避免所有视频同时加载。
  - 选中任务后在下方展示“素材预览”；视频显示时间点，图片包显示文件名。
  - 素材支持查看大图，并可通过“写报告”跳转到报告编写页。
  - 报告编写页根据 `mediaId` 自动加载媒体库图片到标注画布。

### 已验证

- 真实测试视频完成上传、任务创建、FFmpeg 抽帧和 4 张证据帧回写。
- 真实 ZIP 中嵌套目录和重复文件名正确展开为 3 张图片。
- 视频内容接口的 Range 请求返回 `206`、`Content-Range` 和 `Accept-Ranges`。
- 浏览器选中图片包后显示 3 张真实图片，点击“写报告”后图片自动进入报告标注画布。
- API、媒体工作进程和管理端逻辑测试通过，管理端生产构建通过。

### 模块边界

- 本阶段只负责媒体接入、后台处理、任务预览和报告入口。
- AI 识别、事件合并、人工复核和正式报告生成继续作为后续独立模块推进。

## 2026-07-10 真实业务闭环模块 1：工程与数据可信度

### 本阶段目标

- 在接入真实媒体、视频分析任务和 AI 复核流程前，先把工程运行入口和前端数据可信度补齐。
- API 具备生产环境启动校验和公开健康检查。
- 前端接口失败时不再静默显示样例数据，统一展示错误提示和重试入口。
- 列表页和详情页遇到 401、404 或网络错误时，不把本地兜底数据伪装成真实业务数据。

### 新增能力

- 后端运行配置校验：
  - 默认监听 `0.0.0.0:3010`，便于服务器和反向代理访问。
  - 生产环境缺少 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 或 `AUTH_SECRET` 时拒绝启动。
  - 非法端口号会直接报错，避免服务以错误配置启动。
- 健康检查：
  - `GET /api/v1/health`
  - 返回 `{ code: 0, message: "ok", data: { status: "ok" } }`
  - 不需要登录即可访问，便于腾讯云、Nginx 或容器健康探测。
- 前端 API 错误处理：
  - `ApiClientError` 保留 HTTP 状态码和后端错误信息。
  - `useApiResource` 在请求失败时保留错误状态，不再覆盖为样例数据。
  - 401 自动清理无效登录态。
- 统一错误页：
  - 401 显示“登录状态已失效，请重新登录后再试”。
  - 404 显示“该条资料不存在，可能已被删除或没有访问权限”。
  - 其它错误显示后端错误信息或通用加载失败提示。
  - 提供“重新加载”按钮。
- 已接入页面：
  - 首页地图总览。
  - 小区档案列表。
  - 街道档案列表。
  - 重点点位列表。
  - 问题台账列表。
  - 巡检报告列表。
  - 地图资产列表。
  - 操作审计列表。
  - 小区/街道详情。
  - 重点点位详情。
  - 问题详情。
  - 巡检报告详情。
  - 地图资产详情。
