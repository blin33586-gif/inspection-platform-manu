# 巡检宝部署运行说明

## 本地开发运行

```bash
pnpm install
cp .env.example .env
pnpm db:generate
pnpm db:migrate
pnpm db:seed
pnpm dev:api
pnpm dev:admin
```

- 后端默认地址：`http://127.0.0.1:3010/api/v1`
- 前端默认地址：`http://127.0.0.1:5180/`
- 前端接口地址可通过 `VITE_API_BASE_URL` 配置。

本机未安装 PostgreSQL 时，可用以下方式启动独立的本地数据库：

```bash
docker compose -f docker-compose.yml -f docker-compose.local-postgres.yml up --build -d
```

## 腾讯云生产部署

生产数据库使用 **TencentDB for PostgreSQL**。云服务器与数据库实例应位于同地域、同 VPC，并使用数据库内网地址；不要把数据库端口直接暴露到公网。

在服务器 `.env` 中配置 `DATABASE_URL`、管理员账号、密码和 `AUTH_SECRET` 后执行：

```bash
docker compose up --build -d
```

后端容器启动时会自动执行：

```bash
pnpm db:deploy
```

它只应用版本库中已经提交的 Prisma 迁移。生产环境禁止使用 `db:migrate`、`db:push` 或 `db:seed`。

- 管理端入口：`http://服务器IP:8080/`
- 后端接口：`http://服务器IP:3010/api/v1`
- 正式上线只开放 `80/443`，由 Nginx 或云负载均衡转发。

## 数据与文件

- PostgreSQL 保存账号、档案、问题、报告、地图标注和审计数据。
- 地图瓦片、照片、视频和导出报告保存在 `api-storage` volume；腾讯云正式环境应切换至 COS。
- 旧 SQLite 数据库只用于一次性迁移，迁移前请备份源文件。
- 腾讯云数据库启用自动备份与日志备份，并定期保留逻辑备份。

从旧 SQLite 导入历史数据、配置 COS 与灾备的完整流程见 [TencentDB-PostgreSQL 部署与迁移](TencentDB-PostgreSQL部署与迁移.md)。
