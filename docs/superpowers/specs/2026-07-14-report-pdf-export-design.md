# 报告 PDF 导出与长标题排版设计

## 目标

让报告详情页能够直接导出可下载的 PDF 文件，同时修复长标题在页面和 A4 报告封面中溢出的问题。

## 用户体验

- 顶部主按钮改为“导出 PDF”，点击后显示导出中状态，成功后直接下载文件。
- 保留一个次要“打印”入口作为备用能力，但不再把打印窗口当作 PDF 导出。
- 导出失败时留在当前页面并显示明确错误，不打开空白页。
- 下载文件名使用报告标题，清理文件系统不支持的字符，并以 `.pdf` 结尾。

## PDF 生成

- 由服务端提供 `GET /api/v1/reports/:id/pdf`，按照当前项目权限读取报告，不能跨项目导出。
- PDF 内容沿用报告详情的 A4 结构：封面一页，每张报告照片一页。
- 生成过程使用适合中文和图片排版的 HTML 打印引擎；图片按比例缩放，不裁切原始内容。
- 响应使用 `application/pdf` 和下载型 `Content-Disposition`。
- 若报告本身是用户上传的 PDF，原文件下载与本次“生成综合报告 PDF”仍是两个独立能力。

## 长标题规则

- 页面标题和报告封面标题都允许在中文、空格、下划线、连字符及长文件名位置换行。
- 封面标题使用有限字号范围，不因单个超长词撑出 A4 页面。
- 标题最多占用封面预留区域；极端长标题继续换行但不横向溢出。
- 屏幕和打印样式使用同一套换行规则，避免预览正常、导出错位。

## 验收

- 点击“导出 PDF”后得到非空 `.pdf` 文件，而不是只出现浏览器打印窗口。
- 导出期间按钮不可重复触发，失败时有错误提示。
- `历史任务 · DJI_20260708161256_0003_T.mp4综合报告` 在 825px 页面和 A4 PDF 中均不横向溢出。
- 生成的 PDF 包含封面及全部报告照片页，中文可正常阅读。
