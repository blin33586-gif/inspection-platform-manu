# 媒体任务详情页与抽帧间隔设计

## 目标

- 媒体库列表只承担任务检索、筛选和状态查看，不再在列表底部展开大量素材。
- 点击任务进入站内独立详情页，集中查看原始视频、抽帧照片或图片 ZIP 内容。
- 视频上传时允许选择 1 至 5 秒的抽帧间隔，默认 3 秒。

## 页面与路由

### 媒体库列表

- 路由保持 `/media-library`。
- 任务卡继续展示来源、处理状态、关联对象、抽帧间隔、素材数和事件数。
- 点击持久化任务卡跳转到 `/media-library/:taskId`。
- 列表页删除底部 `MediaAssetGallery`，避免任务列表过长和页面信息堆叠。
- 演示任务没有真实媒体 ID 时保持原有前端选择行为，不跳转到不存在的详情页。

### 媒体任务详情

- 新增路由 `/media-library/:taskId`。
- 顶部保留全局导航，并提供“返回媒体库”按钮。
- 展示任务名称、原始文件名、素材类型、处理状态、上传时间、抽帧间隔和素材数量。
- 视频任务展示支持鉴权和 Range 的原始视频播放器。
- 视频抽帧与 ZIP 图片统一展示为素材网格。
- 视频帧以时间点作为标题，ZIP 图片以文件名作为标题。
- 每张图片支持查看大图和“写报告”，报告入口保持 `/reports/write?mediaId=:assetId`。
- 任务处理中显示当前状态；暂无素材时显示明确空状态；请求失败时显示错误信息和重新加载按钮。

## 抽帧间隔

- 上传区提供 `1 秒/帧`、`2 秒/帧`、`3 秒/帧`、`4 秒/帧`、`5 秒/帧`。
- 默认值为 `3 秒/帧`。
- 该参数只影响 MP4/MOV 视频；ZIP 图片包忽略该值。
- API、媒体服务和媒体工作进程统一接受整数 1 至 5。
- 非整数、0 或大于 5 的值返回参数错误，不创建处理任务。
- 重新抽帧继续使用任务当前保存的抽帧间隔。

## 数据流

1. 用户在媒体库选择 1 至 5 秒抽帧间隔并上传视频。
2. 前端将 `intervalSeconds` 与文件一起提交。
3. API 校验参数并创建媒体资产与 `frame_extract` 任务。
4. 媒体工作进程按任务参数调用 FFmpeg。
5. 抽帧完成后，子媒体资产回写数据库。
6. 用户点击任务卡进入详情页，页面读取任务和子素材。
7. 用户从素材网格选择图片进入报告标注页。

## 组件边界

- `MediaLibraryPage`：上传、筛选和任务列表。
- `MediaTaskDetailPage`：任务详情、视频播放器和素材区。
- `MediaAssetGallery`：复用现有图片网格、大图和报告入口。
- 媒体任务适配器：继续负责后端数据到前端任务模型的转换。
- API 和媒体工作进程：只调整抽帧参数合法范围，不修改现有任务存储结构。

## 测试与验收

- API：1 秒和 5 秒可创建抽帧任务；0 秒和 6 秒被拒绝。
- 媒体工作进程：1 秒抽帧命令正确生成，任务输入校验接受 1 至 5。
- 前端逻辑：上传选项包含 1 至 5，持久化任务生成正确详情路由。
- 页面：点击任务进入独立详情页，列表页不再出现素材预览区。
- 详情：视频播放器可读取原始视频，抽帧或 ZIP 图片可预览并进入报告编写。
- 回归：现有视频上传、ZIP 解压、鉴权内容读取和报告图片加载保持通过。

## 非本阶段范围

- 不新增 AI 识别、事件合并或人工复核逻辑。
- 不修改报告编辑器内部标注功能。
- 不打开新的浏览器标签页或系统窗口，详情页使用站内路由跳转。
